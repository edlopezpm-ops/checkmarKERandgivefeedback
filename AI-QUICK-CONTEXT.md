# marKER quick context

Snapshot base `de0a4a65d6d37642e5f7efda66151c4270ec2a02` plus 12 explicitly inventoried working-tree paths; 333 complete source/assets/config/test files in [source/](source/).

marKER is a private single-operator content-preparation app. React/Vite + TypeScript; native Worker auth/D1 + private R2 + Durable Object managed FFmpeg; separate local file/SQLite adapters. Supabase is inactive preparation.

Native Space classification and literal library preparation lead into deterministic campaign proposals, editable recipes, render, exact-result human approval and manual export. This works without AI. Rights/readiness/speech are explicit; missing-label rules never grant them. Editorial posts and Studio variants have separate state/revision models.

Optional local Agents use official Codex managed ChatGPT through a loopback polling bridge with durable run/proposal/effect custody. External MCP uses OAuth PKCE, scoped opaque tokens and fifteen finite tools through the same backend. MCP does not require hosted inference and cannot approve/publish. Hosted SIWC, actual installed Dot conversation and broader social APIs are separate.

One retained tenant/user, native email recovery, optional immutable Google/GitHub linking, Turnstile, Profile and resumable confirmed account deletion are implemented. Private stores/credentials/owner data are excluded from this review repo. Full code, tests, migrations, public config and public media are included.

Hosted analysis stays disabled; physical-phone/creative pilot, actual host integration, provider invoice and restore evidence remain qualified.
