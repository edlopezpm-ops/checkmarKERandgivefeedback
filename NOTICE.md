# Publication scope

This public repository is an explanatory and structural review package for the privately maintained marKER application. It does not grant access to or publish the complete application implementation. No general license to the private application or its brand/media assets is granted by this dossier.

Included: original explanatory prose; functional diagrams; source path/line/symbol/import/call-site and test metadata; file hashes and Git blob identifiers; locked dependency metadata; empty application-schema structure; documentary generation/validation scripts; a prompt for external AI feedback.

Excluded: full application source bodies; actual configuration instance identifiers and owner addresses; environment/secret files; private governance, archives and receipts; auth challenges/cookies/tokens; local/cloud business records; uploaded media, original filenames, transcriptions or real campaign contents; databases/backups; cloud credentials and account stores. Only tracked product inputs are eligible for static generation. No runtime data is sampled.

Source inventories are intentionally not a runnable source bundle. A path or hash identifies a source artifact without disclosing its bytes. Generated schema-only SQLite DDL describes empty table/index/constraint structure, not owner data or a hosted catalog. Supabase preparation is separately identified and not represented as current default persistence.

The package follows the earlier timeKER review pattern. Its combined reading copies repeat chapter text for convenient model ingestion. Machine seals provide integrity and coverage evidence only; they are not independent runtime evidence or certification. Recommendations from external models require maintainer validation against actual current source before implementation.
