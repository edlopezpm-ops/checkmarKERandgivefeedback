# Manual editorial console

The interface starts in English. Environment's English / Español switch changes only interface text and date formatting; it preserves stored product/source/post text. The selected preference stays on the current browser. Each module's single lower-left `help` link opens its illustrated guide; the authenticated Environment help section opens the complete topic index. Select a topic, move between numbered steps and open any screenshot at its original size. Every step has a bilingual image reference and alternative text. Profile and the Agents panel have their own contextual entries. Login/landing are excluded from that manual.

Environment includes **Watch the marKER demo / Ver demo de marKER**, opening the public [55-second demo](/demo/) in a separate tab. It is also available in Settings' shared Environment controls. The film uses real local interactions with fictional data and original cueca-inspired music rendered with documented CC0 harp samples.

Published movie paths are immutable and versioned. `server/demo-media.ts` streams HTTP byte ranges for those two public MP4s because the Static Assets binding can ignore Range and omit Content-Length. A replacement film needs a new versioned filename and its verified byte count in that narrow map and `assets.run_worker_first`; the private Studio media routes keep their existing authentication and storage behavior.

After signing in, the initials button beside Environment opens the account menu with the saved email, Profile and Reload. Hosted Sign out is visible beside the initials. Reload refreshes saved data, including after a revision conflict. YOUR WORKSPACE sits above module navigation; the former eyebrow keeps its spacing with decorative dashes. The landing page has no routine Reload button; an initial loading failure offers retry. Codes and access-help mail use `marker@aekr.io` as sender; the sender is independent of the authorized login address.

After a failed hosted login attempt, Get help opens an email-address form. Submitting it explicitly requests access troubleshooting by email using the existing owner-only recipient boundary and separate durable help rate limits. This sends instructions, never a password, new session or recovery bypass. A generic response does not confirm mailbox receipt. Access-help tests use synthetic mail and real SQLite. The owner approved UAT of the delivered manual console on 2026-10-23; that attestation remains distinct from engineering test logs.

The console starts empty. Register approved product facts, then an account with one or more permitted products. Supported destination names are Instagram, Facebook, TikTok, LinkedIn and X; registering one does not connect an API or request its credentials.

In a product's Space, write a note or import TXT/MD encoded as UTF-8. Imported text is displayed literally, not executed as HTML. Ingress time and optional source date are separate. Files are decoded by the browser; the server receives and validates text, not an asserted media type. This increment admits at most 64,000 characters per source, not multimedia. A campaign selects real stored sources and compatible accounts, then creates explicit empty drafts for manual writing. OpenAI is not simulated. Shared references protect originals from editing/deletion while a campaign needs them.

Review each draft, set an optional absolute schedule and confirm the destination's facts/format/length/permissions manually. Instagram/TikTok drafts cannot become ready without the future validated multimedia pipeline. This increment does not implement automated platform limits. The editor's datetime input uses the computer's timezone; queue dates use each account's configured IANA zone. Exact-time collisions on the same account are rejected across products. Queue filters support product/account/search and a seven-day window in each account's zone.

Copy, export as TXT and open the native account link for manual delivery. These actions preserve status and sources. To record an already completed external result, reopen a ready organic post and supply its evidence link with explicit human confirmation. This is owner-reported evidence, not an API readback. Paid proposals require an explicit proposed currency/budget and remain paused; they have no spending/activation/confirmation path.

Deletion is explicit: remove a post to erase its active text/record; remove its campaign only after all posts are removed; then an unreferenced source can be removed. Removing one post never deletes a shared source. No automatic purge, provider deletion, physical secure erasure, backup deletion or restoration-safe purge replay is promised. There is no hidden content history in the application.

## Development storage

`npm run dev` binds to `127.0.0.1` and serves the local API from the same process. The default store is `.local/workspace.json`; `MARKER_LOCAL_DATA` can select a separate verification path. Run only one development process per data path. Atomic replacement and serialized revision-checked writes prevent overlapping browser edits from silently overwriting one another. A stale form stays open and reports a conflict; recopy unsaved text before reloading. Corrupt/unreadable state fails visibly and is not replaced with an empty workspace.

Ceilings: 4 MiB workspace JSON; 1,000 records in each collection; 64,000 characters/source and 20,000/post; 300,000 bytes per command. These are engineering limits, not platform limits. No public registration, tenancy, team or billing system exists. Local mode trusts OS access and must not be exposed as hosted authentication. Vite denies private governance/data/Git/environment/key paths, checks loopback host/peer and rejects foreign origins.

## Hosted domain review

The owner authorized the test release at https://marker.aekr.io with email-code login similar to aekr.io/analytics. A dedicated D1 database stores authentication verifiers and the revision-checked workspace; no other product's database, session or secret is shared. The sole email is configured server-side. There is no public registration or password. Hosted text state is limited to 1 MiB and starts empty.

Request an eight-digit temporary code from the authorized email, then verify it in the same browser within five minutes. Unknown addresses receive the same generic response without a message. Codes are single-use and permit at most five attempts. Opaque Secure/HttpOnly/SameSite=Strict cookies bind challenges/sessions; only HMAC verifiers are stored. Sessions expire after six hours or thirty idle minutes; logout revokes server state. Hourly/IP/owner/daily admission limits protect requests and mail. Daily scheduled cleanup and request-time cleanup remove expired auth records; provider backups have separate retention. Origin checks protect writes. No code or token enters browser storage, source or application logs.

The owner-specific secret uses Cloudflare secret storage, independently of an ignored local development `.dev.vars`. Cloudflare Email Service is restricted to the configured sender/recipient. The deployed Worker and D1 migration were verified by named resource readback; browser/API checks denied anonymous, forged-cookie and non-owner access. Successful login/write/logout/expiry/replay/concurrency were tested using actual SQLite and synthetic mail. The owner's 2026-10-23 UAT approval accepts the delivered manual/domain slice; it does not retroactively create detailed mailbox or transaction receipts.

The earlier PostgreSQL/Supabase adapter and `migrations/0001_editorial.sql` are inactive preparation, not the deployed route. A future change requires an explicit schema/data/identity migration. The bounded D1 test release does not imply normalized multimedia/jobs/retention infrastructure or completion of all product capabilities.

The static UI alone, including `npm run preview`, has no editorial data API. Use the development server for the local console; use the configured Worker for hosted operation. Private media/processing and the local Agents bridge have their own adapters. The [MCP connector](mcp-connector.md) adds delegated assistant tools and Environment connection controls; its hosted activation and real client verification remain separate. Hosted subscription inference, social integrations and Android require further verified capabilities.
